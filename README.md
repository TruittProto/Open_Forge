## Idea_Forge_Lite

Idea Forge Lite
================

Idea Forge Lite is a lightweight version of Idea Forge Pro, a local language model runner with peer-to-peer syncing capabilities, task management, extreme privacy, and custom themes. Unlike the Pro version, the Lite version is focused on just the core features of Idea Forge, including OLLAMA capabilities, themes, and customizability.

Why Open Source?
--------------------

We believe that the best way to build trust is through transparency. By making Idea Forge Lite open source, we're inviting the community to contribute to its development, improve its features, and modify the code to suit their needs. We're excited to see what you'll do with it!

Features
--------

* OLLAMA capabilities
* Customizable themes
* Modifiable code
