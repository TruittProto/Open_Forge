Quick Guide & Usage Tips

  • Start here: Choose a model in the WebGPU Model dropdown, then select Load WebGPU Model. Keep this tab open while the model initializes.
  • First-time load: The browser downloads model files and caches them. This can take several minutes and use significant disk space, RAM, and GPU memory.
  • Pick a model carefully: Start with a 1.5B–3B model if unsure. 7B–9B models need more memory; 14B models may fail or run very slowly on many systems.
  • Raw Material: Paste notes or drop `.txt`, `.md`, `.json`, `.csv`, or `.log` files into the left panel. Keep inputs focused and reasonably short.
  • Modes: Choose Summary, Essay, Outline, Code, Chart, or Chat before clicking Forge. Chat keeps a conversation history until cleared.
  • Important — Lite vs Full: This Lite file runs a browser-based WebGPU model (WebLLM) and does not connect to Ollama. The full Idea Forge version supports Ollama and can use models served by your local Ollama installation. They are different runtimes.
  • Privacy: Model inference runs on your device, but this page loads its runtime and Chart.js from online CDNs and must download model files on first use. Avoid claiming the page makes no network requests at all.
